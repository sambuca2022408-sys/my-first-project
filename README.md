# My First Project

A simple starter workspace for learning to code with Python and saving work to GitHub.

Getting started

1. Run the example script:

```powershell
python .\hello.py
```

2. Initialize a GitHub repository (create it on github.com or use the `gh` CLI), then push:

```powershell
git remote add origin https://github.com/<your-username>/<repo>.git
git branch -M main
git push -u origin main
```

Resources for beginners

- Python basics: variables, control flow, functions, modules
- Try small projects: calculators, text games, simple file I/O
